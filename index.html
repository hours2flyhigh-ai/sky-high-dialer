Agent PCs sign in with the agent login and pick their PC number. Sheets, settings, states and Start over are only here; agents see the customer card, Start/Pause, Sale made and Do not call.

Add a sheet

Reads the tab named "Dial List" if there is one, otherwise the first tab.

Works only if the sheet is shared as "Anyone with the link can view". Otherwise download it as .xlsx and upload it.

Columns are found by their header: a phone / number column is required; name and state are optional. State lets the dialer skip people outside 8am–9pm their time.

States to dial

Only ticked states are dialed. To dial just a few: press Clear all, then tick the ones you want. Customers in unticked states stay on the list as "State off". Each box shows how many customers are left there and the time there now (orange = outside 8am–9pm).

Do Not Call list empty

Numbers here are never dialed, by the dialer or the Call button, even if they're on a sheet you add later. During a call you can also press Do not call again on the customer card, or DNC on a row.

Several PCs dialing the same sheets

Several PCs: sheets and settings are shared with every PC automatically. Each PC picks its own number when it signs in (1 to "How many PCs"). Each phone number belongs to exactly one PC, so no number is dialed twice. Set this before you start and don't change it mid-day.

A call counts as answered when Zoom reports it connected. Voicemail picking up also counts as answered; hang up and use Retry on that row if you want it redialed.
