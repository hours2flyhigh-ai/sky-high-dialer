States to dial

Only ticked states are dialed. To dial just a few: press Clear all, then tick the ones you want. Customers in unticked states stay on the list as "State off". Each box shows how many customers are left there and the time there now (orange = outside 8am–9pm).

Several PCs dialing the same sheets

Several PCs: sheets and settings are shared with every PC automatically. Each PC picks its own number when it signs in (1 to "How many PCs"). Each phone number belongs to exactly one PC, so no number is dialed twice. Set this before you start and don't change it mid-day.

A call counts as answered when Zoom reports it connected. Voicemail picking up also counts as answered; hang up and use Retry on that row if you want it redialed.
